# 알려진 오탐 — 결함으로 올리기 전에 대조할 것

Ch 12 검수에서 실제로 헛짚었거나 헛짚을 뻔한 것들이다. **새로 헛짚은 게 나오면 여기에 추가한다.**

판별의 공통 원칙: **다른 챕터도 그런지 먼저 확인한다.** 저장소 전체가 일관되게 그렇다면 그건 관례지 결함이 아니다.

```bash
grep -rl "<의심 패턴>" pages/ | wc -l      # 몇 개 페이지가 같은 형태인가
head -1 pages/*-*.md                       # 헤딩 관례 비교
```

## 수치·표기

| 의심 | 실제 | 확인법 |
|---|---|---|
| `66M` 과 `67M` 혼용 | body(66,362,880)와 전체(66,957,317)를 각각 정확히 가리킴 | 실행본의 `Parameters:` 출력과 대조 |
| `eval_loss: 1.0000` — 딱 떨어져 수상 | 실제 `1.000020` 의 반올림 | Trainer 학습 표 원값 확인 |
| 산문의 `0.9030` 이 이 챕터 출력에 없음 | 타 챕터(Ch 10) 실측 인용 | 스크립트가 `C5[교차인용]` 으로 구분해 준다 |
| `0.693` · `1.609` · `2.303` 이 출력에 없음 | $\ln 2$·$\ln 5$·$\ln 10$ — 교육용 상수 | loss 표·softmax 예시 표의 값이다 |

가이드 3쪽이 "실측과 다른 수치"를 Major 로 든 것은 **재현 가능한 값**이 어긋난 경우다. metric·소요 시간처럼 실행마다 달라지는 값은 해당하지 않는다.

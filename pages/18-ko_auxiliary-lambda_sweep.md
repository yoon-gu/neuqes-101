## 18-4. 부록 — λ 스윕으로 약한 보조 신호의 sweet spot 찾기

> ▶ **[Google Colab에서 λ 스윕 부록 열기](https://colab.research.google.com/github/yoon-gu/neuqes-101/blob/master/18_ko_auxiliary/18_ko_auxiliary_lambda_sweep.ipynb)** — Ch 18 본편의 `lambda_aux=0.05` 선택 근거를 직접 재현합니다.

### 질문

Ch 18의 보조 task는 `n_active`, 즉 합성 multi-label 샘플에서 활성 카테고리가 몇 개인지 맞히는 회귀입니다. 메인 multi-label 벡터의 합과 직접 연결되어 있지만, 값이 거의 2에 몰려 있어 정보량은 약합니다.

이 부록의 질문은 다음입니다.

**“약한 보조 신호도 λ를 작게 잡으면 메인 task를 도울 수 있는가?”**

### 실험 조건

| 항목 | 설정 |
|---|---|
| 데이터 | KLUE-YNAT 합성 multi-label |
| 메인 task | 7개 뉴스 카테고리 multi-label 분류 |
| 보조 task | `n_active` 회귀 |
| λ grid | 0, 0.02, 0.05, 0.1, 0.2, 0.5 |
| 비교 방식 | 같은 seed, 같은 초기화 조건의 공정 비교 |
| 평가 지표 | micro-F1, macro-F1, aux R² |

### 결과

| λ | micro-F1 | macro-F1 | aux R² |
|---:|---:|---:|---:|
| 0.0 | 0.8491 | 0.8451 | — |
| 0.02 | 0.8514 | 0.8483 | 0.034 |
| **0.05** | **0.8523** | **0.8493** | 0.065 |
| 0.1 | 0.8489 | 0.8452 | 0.067 |
| 0.2 | 0.8401 | 0.8413 | 0.073 |
| 0.5 | 0.8041 | 0.8197 | 0.081 |

![한국어 보조 손실 λ 스윕에서 확인한 sweet spot](../assets/18-ko_auxiliary-lambda_sweep.png)

### 결과 해석

1. **λ=0.05가 sweet spot입니다.** λ=0 baseline 대비 micro-F1은 0.8491 → 0.8523, macro-F1은 0.8451 → 0.8493으로 올라갑니다.
2. **λ=0.1은 본편 학습값이 아니라 비교점입니다.** 같은 seed 공정 비교에서는 거의 중립이고, λ를 더 키우면 메인 성능이 떨어집니다.
3. **λ≥0.2부터는 보조가 메인을 방해합니다.** 보조 R²는 조금 오르지만 메인 F1은 내려갑니다. 약한 보조 신호에 너무 큰 가중치를 주면 공유 BERT 표현이 메인 분류보다 보조 회귀에 끌려갑니다.

### Ch 14와의 대조

| 장 | 보조 task | 보조 R² | sweet spot Δ(micro) |
|---|---|---:|---:|
| Ch 14 | 별점 회귀 | 0.43 | +0.007 |
| Ch 18 | `n_active` 회귀 | 0.065 | +0.003 |

두 장 모두 sweet spot은 λ=0.05입니다. 차이는 λ가 아니라 **보조 신호의 정보량**입니다. Ch 14의 별점은 입력 리뷰와 강하게 연결된 외부 신호이고, Ch 18의 `n_active`는 값이 거의 2에 몰린 약한 구조 신호입니다. 그래서 둘 다 메인을 돕지만, Ch 18의 개선폭은 더 작습니다.

### 본편과의 연결

Ch 18 본편은 이 스윕 결과를 반영해 `lambda_aux=0.05`를 사용합니다. `lambda_aux=0.1`은 본편 기본값이 아니라, 약한 보조 신호를 조금 더 키웠을 때 효과가 거의 사라지는 비교점입니다.

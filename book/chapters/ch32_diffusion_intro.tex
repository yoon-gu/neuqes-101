\section{먼저 확인할 것: 생성은 됩니다}

\ref{ch:24}--\ref{ch:31}장의 GPT 계열은 왼쪽에서 오른쪽으로 다음 토큰을 하나씩 씁니다. 이 장에서는 방향을 바꿉니다. 작은 BERT-style masked LM을 무작위 초기화에서 시작해 TinyStories로 학습하고, 전부 \inlinecode{[MASK]}인 빈 캔버스에서 문장 전체를 여러 번 복원합니다. 왼쪽에서 오른쪽으로 쓰는 것이 아니라, 여러 위치를 동시에 채워 갑니다.

학습이 끝나면 다음처럼 영어 동화의 형태가 나타납니다.

\begin{quote}
\emph{Once upon a time, there was a boy named Timmy. He had found a big toy ball in the park. He went to a big house with his toys. He liked to play with him.}
\end{quote}

이 결과는 완벽하지 않습니다. 기본 confidence-remasking 샘플러는 문장을 만들지만, 같은 조각을 반복하는 경향이 남습니다. 실제 실행 결과에도 \inlinecode{They run to the park}, \inlinecode{They are happy}, \inlinecode{Ben says} 같은 패턴이 되풀이됩니다. 하지만 이 장의 첫 목표는 \emph{작동}입니다. 작은 모델이 전부 \inlinecode{[MASK]}인 시퀀스에서 시작해 영어 문장 구조를 끌어낸다는 사실을 먼저 확인하고, 반복과 붕괴 원인은 뒤쪽 해부와 오류 실험으로 내립니다.

\begin{quote}
핵심 한 줄은 이렇습니다. \ref{ch:20}장의 BERT MLM은 고정 15\% 마스킹을 한 번 복원했습니다. Diffusion LM은 마스킹 비율을 \(0\)--\(100\%\) 범위로 일반화하고, 복원을 여러 번 반복합니다. 그러면 가려진 토큰 맞히기가 생성이 됩니다.
\end{quote}

\section{Loss: 가변 마스킹 denoising}

깨끗한 토큰 시퀀스 \(x_0=(x_1,\ldots,x_L)\)에서 시간 \(t\sim U(\epsilon,1)\)를 뽑습니다. 각 토큰은 독립적으로 확률 \(t\)만큼 \inlinecode{[MASK]}로 치환되고, 그렇게 만든 중간 상태를 \(x_t\)라고 둡니다. 모델은 \(x_t\) 전체를 보고 가려진 자리의 원본 토큰을 맞힙니다.

\begin{equation}
\label{eq:ch32-diffusion-loss}
\mathcal{L}_{\text{diffusion}}
=
\frac{1}{B}
\sum_{b=1}^{B}
\frac{1}{t_b}
\frac{1}{L}
\sum_{i \in M_b}
\mathrm{CE}\!\left(p_\theta(x_i \mid x_{t_b}), x_i\right)
\end{equation}

식~\eqref{eq:ch32-diffusion-loss}의 \(M_b\)는 \(b\)번째 샘플에서 실제로 가려진 위치 집합입니다. 구현에서는 가려진 자리만 정답 토큰 id를 넣고, 나머지 위치는 \inlinecode{-100}으로 둡니다. \ref{ch:20}장의 MLM, \ref{ch:28}장의 SFT prompt masking과 같은 트릭입니다.

\section{토크나이저 노트: 작은 모델에는 작은 vocab}

Diffusion LM에서 \inlinecode{[MASK]}는 단순한 특수 토큰이 아닙니다. forward process에서는 원본 토큰을 가리는 노이즈이고, reverse process에서는 빈 캔버스입니다. 모든 위치가 \inlinecode{[MASK]}인 상태에서 출발해 토큰을 채우면, 그것이 생성입니다.

작은 from-scratch 모델에는 vocab 크기도 중요합니다. \inlinecode{bert-base-uncased}의 WordPiece vocab은 30,522개라 hidden 256짜리 모델에서는 임베딩이 지나치게 큽니다. 이 장은 TinyStories 코퍼스에 ByteLevel BPE vocab 2048을 직접 학습하고, \inlinecode{[PAD]}, \inlinecode{[UNK]}, \inlinecode{[MASK]}를 special token으로 넣습니다.

토큰화 뒤에는 모든 토큰을 이어 붙이고 \inlinecode{BLOCK\_SIZE=128} 단위로 자릅니다. diffusion은 문장 전체를 하나의 캔버스로 다루므로 \inlinecode{[CLS]}나 \inlinecode{[SEP]}를 붙이지 않습니다.

\begin{lstlisting}
BLOCK_SIZE = 128

def tokenize_fn(batch):
    return tokenizer(batch["text"], add_special_tokens=False)

tok_train = raw_train.map(
    tokenize_fn,
    batched=True,
    remove_columns=raw_train.column_names,
    desc="tokenize train",
)

def group_texts(batch):
    concatenated = {k: sum(batch[k], []) for k in batch.keys()}
    total_len = len(concatenated["input_ids"])
    total_len = (total_len // BLOCK_SIZE) * BLOCK_SIZE
    return {
        k: [t[i : i + BLOCK_SIZE] for i in range(0, total_len, BLOCK_SIZE)]
        for k, t in concatenated.items()
    }

lm_train = tok_train.map(group_texts, batched=True, desc="group train")
\end{lstlisting}

\section{해부: DiffusionCollator}

BERT MLM의 collator는 항상 약 15\%를 가렸습니다. 이 장의 collator는 샘플마다 \(t\sim U(\epsilon,1)\)를 뽑고, 각 토큰을 독립적으로 확률 \(t\)로 \inlinecode{[MASK]}로 바꿉니다. \(\epsilon=0.02\)는 \(t=0\)에 가까운 샘플에서 \(1/t\)가 폭주하지 않게 하는 작은 안전장치입니다.

\begin{lstlisting}
class DiffusionCollator:
    """매 배치마다 t ~ U(eps, 1)을 뽑아 그 비율로 토큰을 [MASK] 치환."""

    def __init__(self, tokenizer, eps=0.02, seed=42):
        self.mask_id = tokenizer.mask_token_id
        self.eps = eps
        self.gen = torch.Generator().manual_seed(seed)

    def __call__(self, examples):
        ids = torch.tensor([e["input_ids"] for e in examples], dtype=torch.long)
        B, L = ids.shape

        t = torch.rand(B, generator=self.gen) * (1.0 - self.eps) + self.eps
        mask = torch.rand(B, L, generator=self.gen) < t.unsqueeze(1)

        no_mask_rows = ~mask.any(dim=1)
        if no_mask_rows.any():
            j = torch.randint(0, L, (int(no_mask_rows.sum()),), generator=self.gen)
            mask[no_mask_rows, j] = True

        input_ids = ids.clone()
        input_ids[mask] = self.mask_id
        labels = ids.clone()
        labels[~mask] = -100

        attention_mask = torch.ones(B, L, dtype=torch.long)
        return {
            "input_ids": input_ids,
            "attention_mask": attention_mask,
            "labels": labels,
            "t": t,
        }
\end{lstlisting}

\section{실습: 병렬 denoise 생성 함수}

생성 함수는 전부 \inlinecode{[MASK]}인 길이 \(L\) 시퀀스에서 시작합니다. 매 step마다 현재 \inlinecode{[MASK]} 위치를 한꺼번에 예측하고, confidence가 낮은 자리만 다시 \inlinecode{[MASK]}로 남깁니다. 이 방식은 LLaDA와 MaskGIT 계열의 low-confidence remasking을 교육용으로 단순화한 것입니다.

\begin{lstlisting}
@torch.no_grad()
def diffusion_generate(active_model, length=64, steps=16, temperature=1.0, top_k=50,
                       prompt_ids=None, record_trajectory=False):
    active_model.eval()
    dev = active_model.device
    mask_id = tokenizer.mask_token_id

    x = torch.full((1, length), mask_id, dtype=torch.long, device=dev)
    fixed = torch.zeros(length, dtype=torch.bool, device=dev)
    if prompt_ids is not None:
        p = torch.tensor(prompt_ids[:length], device=dev)
        x[0, :len(p)] = p
        fixed[:len(p)] = True

    n_gen = int((~fixed).sum().item())
    traj = []
    for step in range(steps):
        logits = active_model(input_ids=x).logits[0]
        probs = logits.softmax(dim=-1)

        scaled = logits / temperature
        if top_k > 0:
            kth = scaled.topk(top_k, dim=-1).values[:, -1, None]
            scaled = scaled.masked_fill(scaled < kth, float("-inf"))
        pred = torch.multinomial(scaled.softmax(-1), 1).squeeze(-1)
        conf = probs.gather(-1, pred.unsqueeze(-1)).squeeze(-1)

        is_mask = (x[0] == mask_id) & (~fixed)
        x_new = torch.where(is_mask, pred, x[0])

        n_remain = int(round(n_gen * (1.0 - (step + 1) / steps)))
        if n_remain > 0:
            conf_masked = conf.clone()
            conf_masked[~is_mask] = float("inf")
            remask_idx = conf_masked.topk(n_remain, largest=False).indices
            x_new[remask_idx] = mask_id

        x[0] = x_new
        if record_trajectory:
            traj.append(x[0].clone())

    text = tokenizer.decode(x[0], skip_special_tokens=True)
    return (text, traj) if record_trajectory else text
\end{lstlisting}

\noindent\textbf{위 코드 읽기.}
\inlinecode{x}는 처음에 모두 mask id입니다. \inlinecode{logits = active\_model(input\_ids=x).logits[0]} 한 번으로 모든 위치의 후보를 동시에 얻습니다. \inlinecode{top\_k=50} sampling은 작은 모델이 최빈 토큰 하나로 무너지는 것을 줄이기 위한 기본값입니다. \inlinecode{n\_remain}은 step이 진행될수록 남겨 둘 \inlinecode{[MASK]} 수를 줄이는 선형 스케줄입니다.

\section{실습: \inlinecode{Trainer}로 30,000 step 학습}

\inlinecode{BertForMaskedLM}의 기본 loss는 가려진 자리 CE 평균입니다. Diffusion loss에는 샘플별 \(1/t\) 가중이 필요하므로 \inlinecode{Trainer.compute\_loss}를 오버라이드합니다.

\begin{lstlisting}
class DiffusionTrainer(Trainer):
    """masked-diffusion loss: 가려진 자리 CE를 샘플별로 1/t 재가중."""

    def compute_loss(self, model, inputs, return_outputs=False, **kwargs):
        t = inputs["t"]
        labels = inputs["labels"]
        outputs = model(
            input_ids=inputs["input_ids"],
            attention_mask=inputs["attention_mask"],
        )
        logits = outputs.logits
        B, L, V = logits.shape

        per_tok = F.cross_entropy(
            logits.view(-1, V),
            labels.view(-1),
            ignore_index=-100,
            reduction="none",
        ).view(B, L)

        per_ex = per_tok.sum(dim=1) / L
        loss = (per_ex / t.to(per_ex.dtype)).mean()
        return (loss, outputs) if return_outputs else loss
\end{lstlisting}

\section{해부: 생성은 되지만 반복이 남는 이유}

학습 후 모델은 전부 \inlinecode{[MASK]}에서 출발해도 영어 동화를 만듭니다. 하지만 \inlinecode{named named}, \inlinecode{was a was a}, \inlinecode{play and play} 같은 반복이 생길 수 있습니다. 이 현상을 모델 학습 실패로만 보면 안 됩니다. \inlinecode{train\_loss}는 3.7148까지 내려갔고, 조건부 구조도 배웠습니다. 남은 문제의 큰 부분은 샘플러입니다.

\section{오류 실험: 붕괴를 주제로 올리지 않는 이유}

이 장의 도입은 ``생성된다''입니다. 그래도 학습자가 직접 바꿔 보다가 만날 수 있는 오류는 정리해 둡니다.

\subsection{오류 1: \(\epsilon=0\)에 가까운 collator}

\inlinecode{t}가 0에 너무 가까우면 \(1/t\)가 커져 loss 스케일이 튈 수 있습니다. 또한 마스크가 하나도 없는 행은 학습 신호가 없습니다. 그래서 collator는 \inlinecode{eps=0.02}를 두고, 그래도 마스크가 하나도 없는 행은 임의의 한 자리를 강제로 가립니다.

\begin{lstlisting}
no_mask_rows = ~mask.any(dim=1)
if no_mask_rows.any():
    j = torch.randint(0, L, (int(no_mask_rows.sum()),), generator=self.gen)
    mask[no_mask_rows, j] = True
\end{lstlisting}

\noindent\textbf{코드 해석.}
이 코드는 diffusion의 본질이 아니라 학습 안정장치입니다. 본문 앞쪽에서 길게 다루지 않는 이유도 여기에 있습니다. 핵심 개념은 가변 마스킹과 반복 denoise이고, \(\epsilon\)은 그 구현을 안정화하는 보조 장치입니다.

\subsection{오류 2: 랜덤 collator와 dataloader worker}

collator 안에서 \inlinecode{torch.Generator()}를 직접 들고 있기 때문에, dataloader worker 수를 늘리면 worker별 난수 상태와 재현성이 예상과 달라질 수 있습니다. Colab 실습에서는 단순성과 재현성을 우선해 기본 worker 설정을 그대로 둡니다. 속도 최적화가 목적이라면 worker별 seed 초기화를 별도로 관리해야 합니다.

\section{FAQ}

\begin{faqBox}{Q1. Diffusion LM은 결국 BERT MLM과 같은 건가요?}
메커니즘은 매우 가깝고, 목적과 사용법이 다릅니다. BERT MLM은 고정 15\%를 한 번 가려 복원하면서 downstream fine-tune에 쓸 표현을 배웁니다. Diffusion LM은 \(t\sim U(\epsilon,1)\)로 마스킹 비율을 바꾸고, 생성 시 복원을 여러 번 반복합니다. 100\%에 가까운 마스킹까지 학습했기 때문에 전부 \inlinecode{[MASK]}인 상태에서 출발할 수 있습니다.

\begin{lstlisting}
# BERT MLM: 고정 비율
mlm_probability = 0.15

# Diffusion LM: 샘플별 가변 비율
t = torch.rand(B) * (1.0 - eps) + eps
mask = torch.rand(B, L) < t.unsqueeze(1)
\end{lstlisting}
\end{faqBox}

\begin{faqBox}{Q2. \(1/t\) 재가중은 왜 필요한가요?}
마스킹 비율이 다른 샘플을 같은 척도에서 비교하기 위해서입니다. \(t=0.05\)이면 가린 토큰이 적어 CE 합이 작고, \(t=0.95\)이면 CE 합이 큽니다. 그대로 평균하면 많이 가린 샘플이 loss를 지배합니다. \(1/t\)를 곱하면 평균적으로 \((tL)\)개 가려진 항을 다시 \(L\) 기준으로 맞추게 됩니다. 실행본의 무작위 기준선이 \(\ln(2048)=7.6246\)으로 정렬되는 이유도 이 때문입니다.
\end{faqBox}

\begin{faqBox}{Q3. 생성 결과가 반복적인데 정상인가요?}
이 장의 설정에서는 정상입니다. \inlinecode{train\_loss}가 3.7148까지 내려갔고, 학습 전 무의미한 토큰 나열과 달리 학습 후에는 TinyStories식 문장 구조가 나옵니다. 다만 기본 confidence-remasking sampler는 고빈도 토큰을 반복 확정하기 쉽습니다. 반복 억제, carry-over, temperature, top-p, repetition penalty 같은 샘플러 개선은 다음 장의 주제입니다.
\end{faqBox}

\begin{faqBox}{Q4. Greedy로 뽑으면 더 안정적이지 않나요?}
작은 모델의 전부 \inlinecode{[MASK]} 시작에서는 오히려 greedy가 무너질 수 있습니다. 첫 step에는 문맥이 거의 없기 때문에 모든 위치에서 최빈 토큰이 높은 점수를 받을 수 있습니다. 그러면 마침표나 흔한 단어가 여러 위치에 한꺼번에 박힙니다. 이 장의 \inlinecode{diffusion\_generate}가 \inlinecode{temperature=1.0}, \inlinecode{top\_k=50} sampling을 기본으로 둔 이유입니다.

\begin{lstlisting}
# 진단용 greedy. 기본 생성에는 sampling을 권장합니다.
text = diffusion_generate(model, length=48, steps=16, temperature=0.0)
\end{lstlisting}
\end{faqBox}

\begin{faqBox}{Q5. Step 수를 늘리면 무조건 좋아지나요?}
어느 정도까지는 좋아지고 이후에는 포화됩니다. \inlinecode{steps=1}은 모든 위치를 한 번에 확정하므로 단어들이 서로 맞지 않습니다. \inlinecode{steps=16}이나 \inlinecode{steps=32}는 이미 채운 단어가 다음 step의 문맥이 되어 더 일관됩니다. 하지만 작은 모델과 단순 sampler에서는 step을 늘려도 반복이 완전히 없어지지 않습니다. 품질은 모델, step 수, sampler가 함께 결정합니다.
\end{faqBox}

\begin{faqBox}{Q6. 왜 vocab 2048을 직접 학습했나요?}
hidden 256, 4 layer짜리 작은 모델에는 큰 vocab이 부담입니다. \inlinecode{bert-base-uncased}의 30,522 vocab이나 GPT-2의 50,257 vocab을 쓰면 임베딩 테이블이 모델 용량을 많이 차지합니다. TinyStories에 ByteLevel BPE 2048을 직접 학습하면 작은 모델의 용량을 본체 학습에 더 쓸 수 있고, \inlinecode{[MASK]}도 special token으로 정확히 추가할 수 있습니다.
\end{faqBox}

\begin{faqBox}{Q7. Diffusion LM이 autoregressive LLM을 대체하나요?}
가까운 실무 표준은 여전히 autoregressive LLM입니다. 품질, 서빙, KV-cache, 도구 생태계가 훨씬 성숙합니다. Diffusion LM은 병렬 생성, infilling, step 수 조절이라는 강점 때문에 대안 패러다임으로 연구가 빠르게 진행되는 중입니다. 이 장의 목적은 대체를 예측하는 것이 아니라, BERT식 마스킹 복원이 생성 모델로 확장되는 원리를 직접 확인하는 것입니다.
\end{faqBox}

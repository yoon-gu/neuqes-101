# Ch 34 한국어 diffusion 붕괴 → 해결 조사 기록

- 작성: 2026-06-20
- 한 줄 요약: **순진한 100% `[MASK]` diffusion은 한국어에서 유니그램으로 붕괴한다. BERT의 고전적 80/10/10 마스킹 트릭이 이를 해결한다.**
- 이 문서는 Ch 34 집필의 원자료이자, "안 되는 것을 과학적으로 규명하고 고치는" 방법론 기록입니다.

---

## 1. 목표와 설정

Ch 33(영어 작은 mask-diffusion LM)이 성공한 뒤, 같은 레시피를 한국어로 옮겨 Ch 34를 만들려 했습니다. 변경점은 "언어/데이터"뿐이라는 게 의도였습니다.

- 데이터: `g0ster/TinyStories-Korean` (Ch 26과 동일), 50,000 stories → 75,941 chunks (~9.7M tokens)
- 토크나이저: ByteLevel BPE vocab 4000 + `[MASK]`
- 모델: `BertForMaskedLM` hidden 256 / 4L / 4H (≈4.29M)
- 목적함수(초기): 흡수형 diffusion, 가변 마스킹 `t~U(0.02,1)`, 시간가중 `1/t` loss, **100% `[MASK]`**
- 환경: 주로 Colab T4(fp16), 일일 GPU 세션 한도에 걸린 뒤로는 로컬 맥 MPS(fp16=False, ~4 step/s)

## 2. 증상 — 순진한 이식의 붕괴

영어 레시피를 그대로 옮기자 생성이 무너졌습니다.

- train_loss **7.06** (baseline ln(4000)=8.29 — 겨우 1.2 하락)
- 고정-t(0.15) top-1 accuracy **0.081** (영어 Ch 33은 0.717)
- 생성: `",. 함께 하루, 큰.!. 수. 그. 그는..."` — 구두점·고빈도 토큰 파편 (유니그램 붕괴)

train_loss가 높으므로 과적합이 아니라 **명백한 underfitting / 유니그램 고착**입니다.

## 3. 실험 로그 — 모든 하이퍼파라미터가 무력

| # | 가설 | 변경 | train_loss | 고정-t acc | 판정 |
|---|---|---|---|---|---|
| iter1 | (이식) | vocab 4000, 기본 | 7.06 | 0.081 | 붕괴 |
| iter2 | 학습 부족 | BLOCK 64, step 64000(2.67배) | 7.08 | 0.068 | **반증** |
| iter3 | 유니그램 끌림 | t=rand² 저마스킹 편향 | 7.19 | 0.068 | **반증** |
| iter4 | 용량 부족 | 모델 3배(hidden 384/6L, 12.4M) | 7.05 | 0.084 | **반증** |
| 저마스킹 | 고-t가 독 | t≤0.30 하드컷 | 7.06 | 0.084 | **반증** |

**결정적 단서**: loss 곡선이 처음부터 끝까지 ~7.0 평탄(7.069 → 7.034 → … → 6.992, 하강 추세 0). 모델은 첫 ~250 step에 유니그램(8.3→7.0)을 빠르게 배우고 **영영 멈춥니다.** step·용량·마스킹분포·BLOCK·lr 무엇을 바꿔도 같은 벽이었습니다.

## 4. 진단 여정 — 반증의 연속

처음엔 "한국어 mask-diffusion은 영어보다 학습이 느리다"고 보고 학습량(step)·용량을 키웠지만 전부 무력했습니다. 적대적 검증 과정에서 두 가지 오진을 걸러냈습니다.

- "`1/t`→`mask_count` 재가중"이 핵심이라는 종합안 → 수식상 **no-op**(현재 식이 이미 마스크 토큰당 평균 CE)임이 증명되어 기각.
- "Ch 26 대비 빠진 `[EOS]`가 원인"이라는 가설 → 성공한 영어 Ch 33에도 `[EOS]`가 없으므로 기각.

step·용량이 다 무력하고 loss가 평탄하다는 사실은 "느린 수렴"이 아니라 **유니그램 attractor에 갇힘**을 가리켰습니다.

## 5. 돌파 — "되는 것"을 대조군으로

방향을 "안 되는 이유 찾기"에서 **"같은 데이터로 무엇이 되는가"**로 틀자 길이 열렸습니다.

| 대조 | 목적함수 | 같은 한국어 데이터 결과 |
|---|---|---|
| **Ch 26** | AR (자기회귀, 좌→우) | **coherent 생성 성공** — "옛날 옛날에 잭이라는 작은 소녀가 있었습니다. 그녀는 가장 좋아하는 책도 있었어요…" |
| 표준 MLM | 고정 15% + **80/10/10** + plain CE + lr 5e-4 | **고정-t acc 0.469, loss 4.27 — 성공** |
| 순진한 diffusion | 가변 마스킹 + **100% [MASK]** + 1/t | acc 0.084 — 붕괴 |

핵심: **같은 데이터·같은 모델 크기인데 AR과 표준 MLM은 되고, 순진한 diffusion만 붕괴.** 즉 데이터·토크나이저·용량 문제가 아니라 **마스킹 방식**이 범인이었습니다.

(참고: Ch 22 한국어 MLM이 붕괴했던 것은 학습 데이터가 ko-wiki 백과사전이라 어려웠기 때문이고, 간단한 TinyStories-Korean에서는 같은 MLM이 잘 됩니다.)

## 6. 해결 — 80/10/10 이식 (iter5)

표준 MLM이 쓰는 재료를 diffusion에 그대로 이식했습니다.

- **80/10/10**: 마스킹 대상으로 뽑힌 자리에 80% `[MASK]` / 10% 랜덤 토큰 / **10% 원본 유지**
- plain CE (`BertForMaskedLM` 기본 loss, `1/t` 제거)
- lr 5e-4
- 가변 마스킹 `t~U(0.05,1)`은 유지 (생성용)

결과:

| 지표 | 순진한 diffusion | **iter5 (80/10/10)** | 표준 MLM |
|---|---|---|---|
| train_loss | 7.06 (붕괴) | **5.29 (벽 돌파)** | 4.27 |
| 고정-t(0.15) acc | 0.084 | **0.467** | 0.469 |

**acc가 0.084 → 0.467로 점프, 표준 MLM과 동급.** infill도 구두점이 아니라 실제 한국어 단어로 채우기 시작했습니다.

### 왜 80/10/10인가
순진한 100% `[MASK]`는 모델이 "`[MASK]`를 보면 그냥 고빈도 토큰을 찍는다"는 지름길을 학습하게 합니다. 한국어는 조사·어미의 유니그램 예측성이 높아 이 지름길의 유혹이 특히 강합니다. 80/10/10의 **10% 원본 유지**는 "마스크 안 된 자리도 문맥으로 검증하라"고, **10% 랜덤 토큰**은 "틀린 입력을 교정하라"고 강제해 지름길을 막습니다. 영어 Ch 33은 데이터가 워낙 단순·반복적이라 100% 마스크로도 버텼지만, 한국어는 이 트릭 없이는 무너집니다.

## 7. 핵심 교훈 (챕터 포인트)

1. **목적함수가 아키텍처·용량보다 결정적일 수 있다.** 같은 모델·데이터에서 AR은 되고 순진한 diffusion은 무너졌다.
2. **유니그램 붕괴는 조용하다.** 에러도 안 나고 loss도 내려가는 듯 보이지만, loss 절대값을 유니그램 엔트로피와 비교하고 고정-t accuracy를 봐야 잡힌다.
3. **"안 되는 것"을 디버깅할 땐 "되는 대조군"을 먼저 찾아라.** 표준 MLM이 같은 데이터로 되는 걸 확인한 순간 범인(마스킹 방식)이 좁혀졌다.
4. **80/10/10은 장식이 아니다.** BERT가 이 비율을 쓴 이유 — 마스크 토큰 의존을 막고 문맥 활용을 강제 — 가 작은 한국어 모델에서 결정적으로 드러난다.

### 부록 — Colab T4 전체 검증 결과 (2026-06-20, 30000 step)

**완전 성공.** 80/10/10 수정판으로 전체 실행 시 생성까지 coherent.

- elapsed **20.11분** (T4, 30분 예산 내), 에러 0

전부 `[MASK]`에서 시작한 **무조건 생성**(carry-over 샘플러):

> 옛날 옛적에 팀이라는 작은 소년이 있었어요. 팀은 장난감 가지고 노는 것을 매우 좋아했지요. 어느 날, 그는 바닥에서 가장 좋아하는 장난감 자동차를 발견했어요. 그 자동차는 아주 빠르게 움직일 수 없어서 슬펐답니다. … 엄마가 방에 들어오며 "팀아, 내가 네 차를 고쳐줄게!"라고 말했죠. … 그들은 함께 장난감 자동차로 즐겁게 놀며 정말 즐거운 시…

> 한때 작은 마을에 팀이라는 어린 소년이 살고 있었습니다. 그는 매우 행복했습니다. 어느 날, 팀은 … 공원에 갔습니다. 그들은 큰 불꽃을 보았습니다. … 엄마가 웃으며 대답했습니다, " 불꽃놀이는 행복하게 만들 수 있어."

인물(팀)·배경(마을·공원)·대화·서사 완비. 영어 Ch 33과 동급 품질. **80/10/10 한 가지로 유니그램 붕괴(acc 0.084)에서 coherent 생성(acc 0.651)으로 완전히 전환됨이 전체 스케일에서 확정.**
